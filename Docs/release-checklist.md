# MVP release checklist (architecture §17)

Each criterion must be verified before release (§21 rule 15).

- **Automated:** tests that run in CI against in-memory Postgres and a fake GitHub (`apps/api/test`).
- **Production:** what to check once on the deployed system (`Docs/deploy-runbook.md`, step 7). Tick it when done.
